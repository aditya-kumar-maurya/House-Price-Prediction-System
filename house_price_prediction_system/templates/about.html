PROJECT OVERVIEW

About This Project

A full-stack machine learning demo for house price estimation and real-estate analytics.

Project Objective

This system estimates a property's price from its location, area, bedrooms, bathrooms, house type, furnishing, parking and year built. It also offers basic analytics, property record management, CSV import, and prediction history.

Important Notes

  • The default dataset is synthetic demo data created by the project.
  • For meaningful real-world estimates, use a clean, representative dataset from the target market.
  • Model predictions are estimates, not financial or property valuation advice.
  • Change default database passwords and Flask secret key before deployment.
  • Use only datasets you are allowed to process.
