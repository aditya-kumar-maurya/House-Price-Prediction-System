# 🏠 House Price Prediction System

## 📌 About the Project

The **House Price Prediction System** is a machine learning web application that predicts house prices based on property details such as city, area, number of bedrooms, bathrooms, house type, furnishing status, parking, and year built.

The application provides an interactive dashboard to explore property data, analyze real estate trends, and understand machine learning model performance.

## ✨ Features

* **House Price Prediction:** Predict estimated property prices using machine learning.
* **Interactive Dashboard:** View property statistics and real estate analytics.
* **Data Visualization:** Explore price distribution, price vs. area, average prices by city, and house type distribution.
* **Property Analysis:** Analyze properties using different features.
* **Prediction History:** Review previous predictions.
* **Model Performance:** Evaluate the model using MAE, RMSE, and R² Score.
* **Database Integration:** Store and manage property data and prediction records.
* **CSV Dataset Support:** Import real estate data for analysis and prediction.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Web Framework:** Flask
* **Machine Learning:** Scikit-learn, Random Forest Regressor
* **Data Processing:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Frontend:** HTML, CSS, JavaScript
* **Database:** PostgreSQL / Supabase

## ⚙️ How It Works

1. Enter the property details.
2. The application processes the input data.
3. The trained machine learning model predicts the estimated house price.
4. Explore real estate charts and analytics through the dashboard.
5. Review prediction history and model performance.

## 🎯 Project Objective

The objective of this project is to apply machine learning to real estate data and build a user-friendly web application that helps users understand property prices and explore housing market trends.

## 👨‍💻 Developed For

This project was developed as a learning project to practice Python, Flask, machine learning, database integration, and data visualization.

## ⚠️ Disclaimer

Predicted prices are estimates based on the available dataset and model. They should not be treated as professional property valuations.
